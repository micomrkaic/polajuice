# Print stocks

Cubes here are chained after the film transform via `--print` (or the
web page's Print selector) - the cinema negative-to-print model.

The three `synthetic_*` stocks shipped are PLACEHOLDERS: parametric
stylizations generated by `tools/make_print_cubes.py`, measured from
nothing, and labeled as such in every stem, TITLE and blurb. They exist
so the print axis is demonstrable out of the box. To supersede them,
drop measured print-emulsion cubes (Kodak 2383/2393, Fuji 3513 class -
the PictureFX packs are the usual source; check their license before
redistributing on a public page) into this directory or data/luts; the
staging catalog already lists those stems and will pick them up on the
next release.
